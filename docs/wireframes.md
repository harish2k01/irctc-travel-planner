# Layout Notes

Desktop uses a 240-pixel collapsible sidebar, 56-pixel header, and compact 12-16 pixel workspace gaps. Collapsed navigation remains icon-based with tooltips. Mobile uses an overlay drawer and preserves the same route hierarchy.

Operational data uses tables or divided rows, not nested cards. Forms use two-column layouts where space permits. The tracker paginates at 20 rows. Calendar cells cap visible events and use agenda overflow. Dialogs close by button, Escape, or backdrop click.

The header shows one section title and the booking-reminder bell. Summary metrics live on Dashboard rather than in every section.
